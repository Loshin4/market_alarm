# 증시알람 v1.9

v1.8의 앱 외부 알림 기능에 해외 기업 실적 일정·결과 수집 보강을 합친 통합본입니다.

## v1.9 해외 실적 보강
- Nasdaq 전체 실적 달력을 날짜별로 재시도하며 수집
- 한 날짜가 실패해도 다른 날짜의 일정은 계속 저장
- 향후 63일 미국 상장기업 실적 일정 확인
- 수집처가 잠깐 비어도 기존 미래 해외 일정을 삭제하지 않음
- Alpha Vantage는 선택형 보조 출처로 사용
- API 키가 없거나 한도에 걸려도 Nasdaq 실적 서프라이즈에서 EPS 결과 보완
- SEC Company Facts에서 매출·영업이익을 추가 확인
- 핵심 해외 기업 결과를 2시간 간격으로 재확인

## 적용
### 이미 v1.8 APK를 설치한 경우
1. v1.9 백엔드 패치의 `collector` 폴더를 GitHub 저장소에 덮어씁니다.
2. `Commit changes`를 누릅니다.
3. `Actions → Update Market Data → Run workflow`를 한 번 실행합니다.
4. 앱에서 새로고침합니다.

APK 재설치는 필요 없습니다.

### v1.8 알림 수정까지 한 번에 적용하는 경우
1. 이 전체 프로젝트를 GitHub 저장소 최상단에 덮어씁니다.
2. `Update Market Data`를 한 번 실행합니다.
3. `Build Android APK`를 실행합니다.
4. 새 APK를 설치하고 알림·정확한 알람 권한을 허용합니다.

이후 새 국내·해외 일정과 결과는 GitHub Actions가 자동 갱신합니다.
