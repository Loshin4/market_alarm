# 증시알람 v1.7

앱을 닫아도 중요 일정·결과를 확인하고, 홈의 유가·공포지수·환율·주요 지수를 앱에서 직접 빠르게 갱신합니다.

## 적용
1. 전체 파일을 GitHub 저장소 최상단에 덮어씁니다.
2. `Update Market Data`를 한 번 실행합니다.
3. `Build Android APK`를 실행해 새 APK를 한 번 설치합니다.
4. 앱의 `상태 → 백그라운드 알림 → 제한 해제`를 한 번 누릅니다.
5. 같은 화면에서 `2분 뒤 알림 테스트`를 누르고 앱을 닫아 실제 도착을 확인합니다.
6. 이후 새 공시·실적 결과는 앱을 닫아도 백그라운드에서 확인합니다.

## 동작 간격
- 앱 백그라운드 일정·결과 확인: Android가 허용하는 범위에서 약 15분 간격
- 홈 시장 지표: 앱이 화면에 열려 있을 때 약 2분 간격 직접 확인
- GitHub 전체 공시·실적 수집: 기존 자동 실행 주기 유지

일정 내용이 바뀌지 않았다면 앱은 작은 상태 파일만 확인하고, 큰 전체 일정 파일은 다시 받지 않아 데이터 사용량을 줄입니다.

Android 절전 모드나 제조사 배터리 정책에 따라 백그라운드 작업은 다소 늦어질 수 있습니다. `제한 해제`를 적용하면 지연 가능성이 줄어듭니다. 최근 앱 목록에서 쓸어 닫는 것은 괜찮지만, 휴대폰 설정에서 앱을 ‘강제 종료’하면 다시 앱을 열 때까지 자동 확인이 중단될 수 있습니다.
