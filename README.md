# 증시알람 v1.5

한국·미국의 경제 일정, 기업 실적 일정과 발표 결과를 GitHub Actions에서 자동 수집하고 Android 앱이 `data/events.json`을 내려받아 표시합니다.

이번 버전은 KIND 목록/달력/상세 페이지를 함께 확인하고, 회사 공식 IR 페이지를 보조 출처로 사용해 국내 실적 일정 누락을 줄였습니다. 앱 화면에는 날짜별 일정 개수, 한국·미국·실적·경제지표 필터, 중요도 우선 표시, 일반 기업 접기, 회사별 일정·결과 연결, 결과 정렬이 포함됩니다.

앱 화면이 변경되어 v1.5 APK는 한 번 설치해야 합니다. 이후 일정과 결과 데이터 갱신에는 APK 재설치가 필요 없습니다.
