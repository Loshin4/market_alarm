# 증시알람 v1.2 — 전체 실적 자동 갱신형

한국·미국의 경제 일정, 중앙은행 일정, 기업 실적 발표와 발표 결과를 GitHub에서 자동 수집하고 안드로이드 앱에 내려주는 독립 앱입니다.

## 가장 중요한 구조

```text
KIND·OpenDART·미국 전체 실적 달력·공식 경제 일정
                    ↓
GitHub Actions가 30분마다 수집
                    ↓
data/events.json 자동 갱신
                    ↓
설치된 앱이 새 데이터를 다운로드
                    ↓
달력·실적 목록·알림 자동 교체
```

`data/**` 파일만 바뀔 때는 APK 빌드가 실행되지 않습니다. 따라서 **새 기업 실적 일정이 추가되거나 발표 시간이 변경되는 것만으로는 APK를 다시 설치하지 않습니다.**

## v1.2에서 바뀐 점

- 관심 종목 기능 제거
- Alpha Vantage `EARNINGS_CALENDAR`의 종목 미지정 방식으로 향후 3개월 미국 전체 실적 일정 수집
- KIND에 공개된 국내 전체 실적·경영실적 발표 일정 수집
- SK하이닉스·한미반도체·인텔·샌디스크 등 특정 회사 고정 일정이 아니라 공식 일정에서 자동 반영
- 같은 회사의 한글·영문 중복 실적 공지 통합
- 회사명 또는 종목코드 검색 추가
- 실적 탭: 전체 / 국내 / 미국 / 중요 / 발표 예정 / 발표 완료
- 새 중요 일정 추가, 일정 변경, 결과 발표 알림
- GitHub 데이터 수집 30분 간격
- 안드로이드 데이터 확인 약 30분 간격
- 미국 기업명은 주요 기업은 한글명, 그 외 기업은 종목코드로 표시

## 처음 적용할 때

1. 이 ZIP 안의 파일과 폴더 전체를 GitHub 저장소 최상단에 업로드합니다.
2. 저장소 첫 화면에 `.github`, `app`, `collector`, `config`, `data`가 바로 보여야 합니다.
3. 기존 GitHub Secrets는 그대로 유지합니다.
   - `DART_API_KEY`
   - `ALPHA_VANTAGE_API_KEY`
4. `Actions → Update Market Data → Run workflow`를 실행합니다.
5. 성공 후 `data/events.json`에서 일정이 생성됐는지 확인합니다.
6. `Actions → Build Android APK → Run workflow`를 실행합니다.
7. 결과물 `market-alarm-apk-v12` 안의 `app-debug.apk`를 한 번 설치합니다.

## 그 이후

- 새 기업 일정: APK 재설치 없음
- 발표 시간 변경: APK 재설치 없음
- 실적 결과 추가: APK 재설치 없음
- 한글 이름 사전이나 앱 화면 기능 자체 변경: 새 APK 필요

## 무료 API 사용량

- 미국 전체 실적 달력은 하루 약 1회 갱신합니다.
- 미국 실적 결과는 무료 제한을 지키기 위해 하루 최대 20개 기업을 중요도와 발표 시각 순으로 확인합니다.
- 일정 자체는 결과 확인 대상과 관계없이 전체 목록을 저장합니다.
- 국내 실적 결과는 OpenDART 공식 공시 검색을 사용합니다.
