# 증시알람 v1.2.1 — 국내 실적 누락 수정본

v1.2에서 삼성전자·SK하이닉스 일정이 사라진 원인을 수정한 전체 프로젝트입니다.

## 원인

KIND의 IR 일정 목록은 페이지 이동을 폼 전송(POST)으로 처리합니다. 기존 수집기는 `pageIndex`를 GET으로 보내서 1페이지만 반복해서 읽었습니다. 그 결과 2페이지 이후의 삼성전자·SK하이닉스 일정이 수집되지 않았고, 수집 자체는 성공한 것으로 판단되어 이전 일정까지 제거됐습니다.

## 수정 내용

- KIND 페이지 이동을 POST 방식으로 변경
- 현재 페이지와 전체 페이지 수 검증
- 같은 페이지가 반복되면 성공으로 처리하지 않고 이전 정상 데이터 유지
- 삼성전자·SK하이닉스처럼 뒤쪽 페이지에 있는 일정도 전체 페이지에서 수집
- 날짜·시간 변경 시 같은 일정으로 인식하도록 회사+실적기간 기반 ID 사용
- 한글·영문 중복 공지는 한글 공지를 우선
- 한 번 누락됐다고 미래 일정을 바로 삭제하지 않고, 정상 수집에서 3회 연속 누락된 경우에만 제거
- `collector/**` 변경으로 APK 빌드가 실행되지 않도록 빌드 경로 제한

## 적용 방법

1. ZIP을 압축 해제합니다.
2. 안쪽 파일과 폴더를 GitHub 저장소 최상단에 업로드합니다.
3. `Commit changes`를 누릅니다.
4. `Actions → Update Market Data → Run workflow`를 실행합니다.
5. 성공 후 `data/events.json`에서 `SK하이닉스`, `삼성전자`를 검색합니다.
6. 휴대폰 앱에서 `새로고침`을 누릅니다.

**APK 재설치와 APK 재빌드는 필요 없습니다.** 이번 수정은 일정 수집기만 바뀝니다.

## 자동 업데이트 구조

```text
KIND 전체 페이지 자동 수집
        ↓
GitHub Actions가 30분마다 events.json 갱신
        ↓
설치된 앱이 새 JSON 다운로드
        ↓
새 기업 일정·시간 변경 자동 반영
```
